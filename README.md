# 🌌 XENO Hardware Monitor
Experience ultimate system telemetry with this high-tech dark-themed monitor built with WPF and .NET 8. Featuring vibrant neon glowing graphs and real-time hardware tracking, it delivers precision performance monitoring with an iconic MSI Afterburner aesthetic.

## 🚀 Features
- 💻 **Real-Time Tracking**: CPU usage, clock speed (GHz), and temperatures.
- 🎮 **GPU & VRAM Metrics**: Direct monitoring of GPU temperature and VRAM utilization.
- 📈 **Neon Glowing Graphs**: Dynamic 6-module graph paths upgraded with linear scaling and ghost texture lines.
- 🎨 **MSI Afterburner Aesthetic**: Dark-mode user interface stylized with vibrant cyan, orange, and green neon accents.

## 🛠️ How to Use / Build
1. Clone or download this repository.
2. Open the terminal in the directory and run: `dotnet build`
3. Run the executable generated inside the `bin/Debug/net8.0-windows/` folder.
